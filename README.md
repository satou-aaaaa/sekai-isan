# 世界遺産あて

法隆寺・姫路城・屋久島・富士山……日本の世界遺産27件の、ある都道府県・登録の年・文化か自然か・特徴・ふくまれる場所を当てる1日5問のゲーム。知らなくても遊べます。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/sekai-isan/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・一発で何問当てられるか）、解いた種類が集まる「遺産帳」があります。
- 問題は「特徴から当てる」「文化か自然か」「ある都道府県」「登録の年」「どっちが先」「ふくまれる場所」「登録の順」「同じ年の仲間」「いくつから成る」「豆知識から」など。正解すると、その遺産の札（正式な名前・区分・都道府県・年・特徴）と「なぜ」と出典、多くの問題で解説のページから取った豆知識が1つ出ます。
- 問題は520問（13種類）。チケット・回数制限はありません。
- 文字の大きさは3段から選べます。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 中身の出どころ

- [文化庁「世界遺産一覧」](https://www.bunka.go.jp/seisaku/bunkazai/shokai/sekai_isan/ichiran/)：名前・ある都道府県・登録（記載）の年・文化遺産か自然遺産か
- [文化庁「文化遺産オンライン」世界遺産の解説](https://online.bunka.go.jp/special_content/world/)：文化遺産の特徴・ふくまれる場所・構成資産の数
- [環境省「日本の世界自然遺産」](https://www.env.go.jp/nature/isan/worldheritage/)：自然遺産の特徴（各地の顕著な普遍的価値）

2026年の飛鳥・藤原の宮都の登録までを入れています。名前は短くしたものがあり、正式な名前は正解のあとの札に出ます。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：画面を開くと文字（Google Fonts）のために Google へつなぐので、文字が端末に保存済みでも Google に IP アドレスが届くことがあります。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
